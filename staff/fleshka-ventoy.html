Как загрузиться с флешки? Клавиши Boot Menu и BIOS для всех популярных ноутбуков и плат. Клавиши Boot и BIOS Особые случаи

Установочная флешка Windows

Флешка Ventoy ~32 ГБ: три версии Windows, частичная автоустановка, набор программ и сервисных утилит. Грузится на любых ПК — в режиме UEFI и в Legacy BIOS.

Образы

Windows 11 25H2 2018 и новее

Полноценная актуальная система для новых устройств. Без проверки TPM и Secure Boot, без аккаунта Microsoft. Лишние встроенные приложения и реклама убираются при установке.

Windows 10 IoT LTSC 2021 2011–2019

Облегчённая Windows 10 без Магазина и встроенных приложений — для ПК старше 2020 года и слабого железа. Обновления безопасности до 2032 года.

Windows 7 SP1 x64 до 2011–2012

Для очень старых ПК: Core 2, первые Core i, до 4 ГБ памяти. Новее 2012 года — уже Windows 10: нет драйверов USB 3.0 и NVMe.

WinPE Sergei Strelec реанимация

Живая Windows с флешки, без установки: спасение файлов, разметка и клонирование дисков, сброс пароля, восстановление загрузки, проверка железа и вирусов. Не устанавливает систему.

Сертификаты и сайтыWindows 7 получает полный пакет обновлений UpdatePack7R2, свежие корневые сертификаты, TLS 1.2, .NET 4.8 и современный браузер — открываются сайты, работают программы и мессенджеры. Windows 10/11 — поддерживаемые системы, сертификаты обновляются сами через Центр обновления.
АвтоустановкаВручную — только выбор диска (и редакции в Win11). Остальное ставится само: учётная запись, настройки, программы.
ПрограммыБраузеры, архиватор, видео- и фотопросмотрщики, PDF, системные библиотеки.
УтилитыПапка «Сервис»: диагностика, диски, лечение от вирусов, драйверы. Без установки, лёгкая копия кладётся на рабочий стол.

Порядок установки

  1. Загрузка с флешки. Вставьте флешку, включите ПК, вызовите Boot Menu (клавиши) и выберите флешку.
    • Режим определяет разметку системного диска: в UEFI Windows ставится только на диск GPT, в Legacy — только на MBR. Текущий режим показан внизу меню Ventoy.
    • Windows 10/11 — UEFI. Windows 7 и старые ПК без UEFI — Legacy.
    • Флешка может быть в списке дважды: с пометкой UEFI: — загрузка в UEFI, без неё — в Legacy.
  2. Выбор образа. Выберите образ в меню Ventoy → Enter. В следующем меню выделен шаблон автоустановки → Enter.
    • Ручная установка без автоматики — пункт без шаблона.
  3. Работа с диском — окно «Где вы хотите установить Windows?».
    • Диски нумеруются: Диск 0, Диск 1… У каждого — свои разделы. Ориентируйтесь по размеру: определите, какой диск системный (обычно SSD), а какой — флешка и диски с данными.
    • Новый или чистый диск: выберите «Незанятое пространство» → «Далее». Служебные разделы создадутся сами.
    • Переустановка: на системном диске удалите разделы старой Windows (системный, MSR, восстановления, основной), выберите появившееся незанятое пространство → «Далее».
    • Сохранить данные: разделы с документами (бывший D:) не удаляйте и не форматируйте.
    • Ошибка «выбранный диск имеет стиль разделов GPT/MBR»: диск размечен под другой режим. Удалите на нём все разделы — установщик переразметит его сам. Либо перезагрузитесь в другом режиме (шаг 1).
    • Список дисков пуст или нет родного диска ноутбука — см. Особые случаи → «Установщик не видит диск».
  4. Редакция — только в Windows 11: «У меня нет ключа продукта» → Pro.
  5. Автоматическая часть. Создаётся учётная запись User (администратор, без пароля), выполняется вход, открывается окно «Донастройка Windows»: настройки, программы, перезагрузка.
    • Windows 11 и LTSC — ориентировочно 20–40 минут.
    • Windows 7 — 1–2 часа, несколько перезагрузок: сначала обновления, потом программы.
  6. Готово, когда после последней перезагрузки на рабочем столе есть «Что делать после установки.txt» и папка «Сервис». В нём — дальнейшие шаги: драйверы, обновления, проверка ПК, активация.

⚠ Внимание

  • Флешка видна в списке дисков — примерно 29 ГБ (флешка 32 ГБ). Не удаляйте на ней разделы: пропадут образы и вся автоустановка. Если сомневаетесь, какой диск системный, — отключите лишние диски.
  • Удаление раздела стирает его данные безвозвратно. Перед удалением проверьте размер и номер диска.
  • Не вынимайте флешку, не закрывайте окно «Донастройка Windows» и не выключайте ПК, пока окно открыто: программы ставятся с флешки.

Полезно знать

Особые случаи: нет диска, нет Wi-Fi, Snapdragon, BitLocker, Home вместо Pro…

  • Перед установкой: сохраните данные владельца (WinPE на этой флешке грузится без установки), ноутбук — на зарядке, диск не зашифрован BitLocker.
  • Лицензия в BIOS: Windows 10/11 той же редакции, что была с завода (Home → Home, Pro → Pro), активируется сама при подключении к интернету. LTSC и Windows 7 этим ключом не активируются.
  • Дата и время в BIOS: неверная дата (севшая батарейка на старых ПК) — ошибки сертификатов, не открываются сайты, не ставятся обновления. Проверьте до установки.
  • Ноутбук с Windows по гарантии: переустановка стирает раздел восстановления производителя — сначала уточните у владельца.
  • Windows 7: режим Legacy/CSM и порт USB 2.0 (чёрный). На синих портах USB 3.0 флешка, клавиатура и мышь могут не работать.
  • Не успеваете нажать клавишу (быстрая загрузка): из Windows — Пуск → Выключение → Shift + «Перезагрузка» → Поиск и устранение неисправностей → Дополнительные параметры → Параметры встроенного ПО UEFI.
  • Синий экран «Verification failed» (Secure Boot): отключите Secure Boot в BIOS (вкладка Security или Boot) либо OK → «Enroll key from disk» → VTOYEFI → ENROLL_THIS_KEY_IN_MOKMANAGER.cer → Continue → Yes → Reboot (один раз на ПК).
  • Флешки нет в списке для Windows 7: включите в BIOS CSM / Legacy Support (иногда сначала нужно отключить Secure Boot).
  • Активации нет ни в одной системе — выполняется отдельно.
  • Что-то не установилось — журнал C:\Windows\Temp\postinstall.log.

Особые случаи

Проблемы конкретных ноутбуков и неподходящих сборок Windows — при установке и после неё.

Установщик не видит диск Thunderobot и др.

Ноутбук на Intel 11-го поколения и новее, в BIOS диск есть, а в окне выбора диска пусто или только флешка. Причина — режим Intel VMD / RST: диск работает через контроллер, драйвера которого нет в установщике Windows.

Чаще всего: Thunderobot и другие китайские игровые ноутбуки (Machenike, Mechrevo и т. п.); Dell (Inspiron, Vostro, Latitude, XPS), HP (Pavilion, Envy, Omen), ASUS (Zenbook, Vivobook, ROG), Lenovo (IdeaPad, Yoga, ThinkPad), Acer (Swift, Aspire), MSI, dynabook. На Intel Core Ultra 200V (Lunar Lake) и новее проблемы обычно нет.

  1. Отключить VMD в BIOS — самый простой путь. Пункт обычно в Advanced → System Agent / Storage / VMD Setup Menu: Enable VMD controller → Disabled (или режим SATA: AHCI вместо RAID/RST). Сохранить (F10), загрузиться с флешки заново — диск появится.
    Только для чистой установки: на уже установленной Windows смена режима ломает загрузку. У части моделей (в т. ч. Thunderobot) пункта может не быть — тогда шаг 2.
  2. Загрузить драйвер в установщике. В окне выбора диска — «Загрузить драйвер» → «Обзор» → папка с драйвером Intel RST VMD (файл iaStorVD.inf) → выбрать Intel RST VMD Controller → «Далее». Диск появится в списке.
    Драйвер — с сайта производителя по модели ноутбука (раздел Storage / Chipset / Intel RST) или с сайта Intel, распакованный, на любой флешке. Если не встал — попробуйте другую версию: старые драйверы не работают на Intel 12–14-го поколения.
  3. Через WinPE на этой флешке: в WinPE Sergei Strelec драйверы Intel RST/VMD, как правило, уже встроены — им можно разметить диск, перенести данные или проверить, что SSD исправен.

После установки нет Wi-Fi Huawei, Honor и др.

Windows не знает сетевую карту ноутбука: в Диспетчере устройств «Сетевой контроллер» с жёлтым значком, значка Wi-Fi нет. Типично для Huawei MateBook и Honor MagicBook (Intel AX201/AX211, Realtek, Qualcomm), а также Xiaomi и китайских ноутбуков.

  1. Intel Wi-Fi — драйвер уже есть: «Сервис\Драйверы\Сеть\WiFi-24.80…exe» на рабочем столе.
  2. Realtek, Qualcomm, MediaTek — офлайн SDIO с флешки (пакет WLAN-WiFi): <флешка>\Сервис\Драйверы\SDIO\SDIO_x64_R891.exe.
  3. Подключить интернет другим способом и поставить драйвер через Центр обновления, SDIO или сайт производителя (у Huawei — PC Manager → Драйверы).

Как дать интернет без Wi-Fi:

  • Кабель в LAN-порт ноутбука, а если порта нет — через переходник Type-C → Ethernet (или USB → Ethernet). Большинство переходников (Realtek RTL8153 и аналоги) работают в Windows 10/11 сразу, без драйверов.
  • Телефон Android по USB: Настройки → Точка доступа → USB-модем. Работает без драйверов.
  • iPhone как USB-модем требует драйвера Apple — без интернета не подойдёт; используйте кабель или Android.

Ноутбук на Snapdragon (ARM) не загрузится

Surface Pro 11 / Laptop 7, Lenovo Yoga Slim 7x и ThinkPad T14s Gen 6, ASUS Vivobook S15, Dell XPS 13 9345, HP OmniBook X и другие на Snapdragon X. Процессор ARM — образы с этой флешки (x64) на нём не запускаются. Нужна Windows 11 ARM64 с сайта Microsoft. Проверить: в описании модели процессор «Snapdragon» / «Qualcomm».

Не работает тачпад

На новых ноутбуках тачпад подключён по шине I2C: в установщике и сразу после установки он может не работать. Подключите USB-мышь, затем поставьте драйвер Intel Serial IO / AMD I2C (SDIO или сайт производителя) — тачпад заработает.

Встала Windows 11 Home вместо Pro

Если в BIOS ноутбука зашит ключ Home (у большинства магазинных ноутбуков), установщик ставит Home без выбора редакции.

  • Перевод в Pro: Параметры → Система → Активация → Изменить ключ продукта → VK7JG-NPHTM-C97JM-9MPGT-3V66T → перезагрузка. Это общий ключ установки: редакция станет Pro, но не активирована.
  • Лицензия Home из BIOS активирует только Home. Нужна активная система без своего ключа — оставляйте Home.

Шифрование диска BitLocker Win11

Windows 11 (24H2 и новее) при чистой установке может сама зашифровать диск. С локальной учётной записью ключ восстановления никуда не сохраняется — после замены платы, сброса BIOS или ремонта данные будут недоступны.

  • Проверить и выключить: Параметры → Конфиденциальность и защита → Шифрование устройства → Откл. (или командная строка от администратора: manage-bde -status, затем manage-bde -off C:).
  • Перед переустановкой чужого ПК: если диск зашифрован (значок замка на диске), сначала сохраните данные или получите ключ восстановления у владельца.

Сборка Windows не подходит под железо

  • Только Windows 11: Wi-Fi 7 (Intel BE200/BE201), камеры Intel MIPI (новые Dell, Lenovo, HP), часть Core Ultra — в LTSC 2021 драйверов не будет.
  • Intel 12-го поколения и новее (P- и E-ядра) — лучше Windows 11: Windows 10 хуже распределяет нагрузку по ядрам.
  • Windows 7 на ПК новее ~2015 года (Intel Skylake / AMD Ryzen): нет драйверов USB 3.0, NVMe и графики — работать не будет.
  • Старые планшеты и нетбуки на Atom с 32-битным UEFI — 64-битная Windows не загрузится.

Драйверы — только от производителя ноутбука

SDIO ставит универсальные драйверы. Для этих устройств берите драйвер с сайта производителя по модели:

  • Звук с «умными» усилителями (Huawei, ASUS, Lenovo, Dell): с универсальным Realtek — тихо, хрипит или нет звука.
  • Две видеокарты (Intel/AMD + NVIDIA): сначала встроенная графика, потом NVIDIA; если драйвер с сайта NVIDIA не ставится — драйвер с сайта ноутбука.
  • Fn-клавиши, режимы питания и кулеров, сканер отпечатка — утилита производителя: Huawei PC Manager, Lenovo Vantage, MyASUS, HP Support Assistant, Dell SupportAssist.
  • Ноутбуки на AMD — драйвер чипсета AMD, иначе проблемы со сном и быстрый разряд батареи.
