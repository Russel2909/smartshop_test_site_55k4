# SmartShop

Статический сайт сервиса ремонта смартфонов и ноутбуков SmartShop: Москва, Каширское шоссе, 55к4, телефон +7 916 726-68-17.

Калькулятор считает стоимость работы по каталогу моделей (`Data/devices.json`). Для замены дисплея и запчасти цена детали в сумму не входит.

## Как посмотреть локально

Из корня репозитория:

```bash
python3 -m http.server 4173
```

Откройте http://127.0.0.1:4173/

Каталог загружается запросом к `Data/devices.json`. Если открыть `index.html` двойным щелчком, браузер этот запрос заблокирует.

## Как публикуется

GitHub Pages, ветка `main`, папка `/` (корень репозитория). Сборки нет: на хостинг попадают HTML, CSS, JS и JSON как есть.

Прежняя версия черновика сохранена в ветке `old-draft`.
