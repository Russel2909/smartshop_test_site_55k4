# SmartShop

Статический сайт сервиса ремонта смартфонов и ноутбуков SmartShop: Москва, Каширское шоссе, 55к4, телефон +7 916 726-68-17.

Страницы: главная, о сервисе, гарантия. Запись и стоимость — по телефону. Калькулятора на сайте нет.

## Как посмотреть локально

Из корня репозитория:

```bash
python3 -m http.server 4173
```

Откройте http://127.0.0.1:4173/

## Как публикуется

GitHub Pages, ветка `main`, папка `/` (корень репозитория). Сборки нет: на хостинг попадают HTML, CSS и JS как есть.

Прежняя версия черновика сохранена в ветке `old-draft`.

## Домен

Сайт рассчитан на корень домена `smartshop.moscow`. В корне репозитория лежит файл `CNAME` с этой строкой. Ссылки внутри сайта относительные (`about.html`, `style.css`, `assets/logo.webp`) и открываются и с корня домена, и с локального сервера.

DNS на REG.RU настраивает владелец. Этот репозиторий записи DNS не меняет:

- A-записи для `@`: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
- CNAME `www` → `russel2909.github.io`
